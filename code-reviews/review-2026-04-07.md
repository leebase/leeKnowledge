# Code Review — 2026-04-07

## Architecture Summary
leeKnowledge is a local-first, four-stage pipeline: extraction captures raw X bookmark GraphQL payloads into immutable JSON before any SQLite mutation, normalization deduplicates canonical bookmark rows by `tweet_id`, enrichment resolves URLs and calls a local `pi`/codex CLI model to persist one enrichment row per bookmark, and export renders Markdown notes into a date-organized vault. The main risk areas here are sync integrity across reruns, export-time schema/bootstrap behavior, and Markdown fidelity because bookmark text and page metadata come from external sources and can contain characters that alter rendered notes if they are not escaped.

| R003 | Medium | Markdown Quality | `src/leeknowledge/templates/bookmark.md.j2:52-69` and `src/leeknowledge/exporter.py:279-333` | Tweet text, summary text, and resolved-link labels/descriptions are interpolated into Markdown without escaping. A real bookmark containing `#`, `*`, `[link](...)`, or similar syntax will change the rendered structure and no longer preserve the source text faithfully. | Escape Markdown-sensitive text before rendering, or render source tweet text and summaries in fenced literal blocks so the exported note preserves content verbatim. Apply the same escaping to link labels/descriptions. |
