# Skill: Markdown Vault Architect

> Load this skill when designing or changing note templates, frontmatter, or vault layout.

---

## Purpose

Design user-visible Markdown artifacts that are readable, source-grounded, and
work cleanly in Obsidian or any plain-text workflow.

---

## Use This Skill When

- Implementing `src/leeknowledge/exporter.py`
- Revising frontmatter fields
- Designing note bodies, topic pages, or synthesis notes
- Evaluating whether output is actually useful to read later

---

## Required Inputs

- Canonical bookmark schema
- Enrichment schema
- Vault structure rules
- Example records or notes

---

## Output Format

- Markdown template plan
- Frontmatter contract
- Example rendered note
- Golden-test guidance

---

## Guardrails

- Original source text must remain visible
- Provenance fields must be preserved
- Missing context should be shown, not hidden
- LLM output must be clearly additive to source facts

---

## Completion Criteria

- Template is explicit
- Required frontmatter fields are named
- Example output is acceptable for daily use
- Golden tests or sample-note checks are identified
